# Un-Nag Mod for Wurm Unlimited (Client)

This mod can be used to block certain annoying UI components and BML windows from appearing in the game.

## Configuration

Edit the `mods/unnag.config`

`bannedUiComponentClassKeywords` controls which UI components are blocked. Any component whose class name contains one of the keywords (case-insensitive) will be blocked.

`bannedBmlTitleKeywords` controls which BML window titles are blocked. Any window whose title contains one of the keywords (case-insensitive) will be blocked.

## Dependencies

Requires [Ago's Client Mod Launcher](https://github.com/ago1024/WurmClientModLauncher/releases) to run.
